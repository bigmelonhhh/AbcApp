# v2.1 版本功能清单说明文档

咕咕 ABC 2.1（versionCode 3）为横屏 Android 平板新增「颜色乐园」。动物、水果、交通工具、生活用品的 14 课和 42 个词继续从首页进入。原词汇流程见 [v2 功能清单](v2版本功能清单说明文档.md)。

## 首页与颜色活动

首页左侧是颜色乐园，右侧是四个词汇分类。底部可打开「我的贴纸」，右上角「家长」点击即可打开。颜色乐园默认选中红黄蓝，绿橙紫同样可直接选择。

| 活动 | 交互 |
| --- | --- |
| 认识颜色 | 每组三张图卡，展示纯色色块、中英文名称和气球、积木或小汽车，可前后翻页、点击重听。每次重新进入轮换示例物品。 |
| 同色配对 | 看目标物品，从两个同形状、不同颜色的选项中找出同色物品。第二、三题的目标与选项采用不同物品。 |
| 听音找色 | 听当前颜色的名称，从两个无可见文字的色块中选择，可重听。全局静音时显示目标色块。 |
| 颜色小画家 | 按颜色提示点选颜料，依次填满三只气球；完成页展示作品，作品随当轮结束，不写入照片或文件。 |

每轮游戏三题，组内颜色各做一次目标和干扰项，正确选项位置有变化。答错时标出目标并重播颜色名，约 1.5 秒后可重试。答对后有提示音，由宝宝点「下一个」或「完成」。完成页可以重玩、换玩法或休息，并给一条生活中找颜色的亲子提示。

## 贴纸、声音与时长

- 完成一轮游戏解锁该组的三枚颜色贴纸，重复完成不会增加重复贴纸。贴纸册单独显示颜色分组和参与记录说明。已解锁贴纸可点读。
- 家长可在「颜色提示」一行切换中文辅助和英文。中文辅助先播中文颜色名，再播英文；同色配对的操作指令在两档分别使用中文和英文。全局静音同时作用于两类内容。
- 颜色图卡、游戏和答题反馈与词汇课程共享每日 300 秒。颜色菜单、结果页和贴纸册不计时。额度用尽时停止音频并显示休息页；未完成的游戏不发奖励。入口和重玩在本机设置完成恢复后检查同一额度。
- 退后台会停播并暂停错题示范计时，回到当前页后按当前状态恢复提示。设置和贴纸保存在本机。重新启动进入首页，原词汇贴纸和额度记录沿用原有键。

## 资源维护

六色及分组定义在 `ColorLearning.kt`，色值统一由 `GuguTokens.kt` 提供。气球、积木与汽车通过 Compose Canvas 矢量绘制，共用色值。14 条颜色语音全部打包为本地 OGG。来源和生成方式见 [颜色资源说明](v2.1新增资源记录.md)。应用保持离线运行，颜色乐园不新增权限声明或运行时授权。调试包合并清单包含既有 AndroidX 依赖声明的任务重排权限和签名级动态广播接收器权限。
