# v2.1 颜色乐园资源记录

## 插画与配色

气球、积木和小汽车是本项目为颜色玩法绘制的矢量图形，源代码在 `screens/ColorArt.kt`。三种图形使用相同色值，轮廓和高光与填色分开。首页、颜色图卡、题目、画作和贴纸调用同一套图形。

| 色名 | 英文 | 色值 |
| --- | --- | --- |
| 红色 | Red | `#DB373E` |
| 黄色 | Yellow | `#F3D33B` |
| 蓝色 | Blue | `#2871DB` |
| 绿色 | Green | `#32A354` |
| 橙色 | Orange | `#F48B24` |
| 紫色 | Purple | `#853EC0` |

## 离线音频

`src/main/res/raw/` 新增 14 条 OGG，而四类词汇的 42 条原发音继续使用既有文件。

- 六个英文单词使用 `color_<id>_en.ogg`，六个中英合成片段使用 `color_<id>_bilingual.ogg`。双语片段先普通话后英语，中间带停顿。
- 同色配对说明使用 `color_match_zh.ogg` 和 `color_match_en.ogg`，分别为“找一个颜色一样的”和 “Find the same color”。
- 使用 Piper 2023.11.14-2，语速参数 `length_scale=1.15`。英语使用 [Lessac medium 模型](https://huggingface.co/rhasspy/piper-voices/blob/main/en/en_US/lessac/medium/MODEL_CARD)，普通话使用 [Huayan medium 模型](https://huggingface.co/rhasspy/piper-voices/blob/217ddc79818708b078d0d14a8fae9608b9d77141/zh/zh_CN/huayan/medium/MODEL_CARD)。Huayan 模型卡将训练数据许可记为 Unknown，来源说明同时随 APK 打包。
- 文件规格为 22050 Hz 单声道 OGG Vorbis，峰值归一化至约 -3 dBFS。运行时使用本地播放器。

重新生成时设置 `GUGU_PIPER_EXE`、`GUGU_PIPER_MODEL`、`GUGU_COLOR_ZH_MODEL` 和 `GUGU_LIBSNDFILE`。ONNX 文件旁应有同名的 `.onnx.json`。从 `app/` 执行 `python tools/prepare_color_audio.py` 可先生成试听文件，追加 `--commit` 才覆盖应用资源。中文字体子集包含六色和新界面文案，继续使用原字体许可。
