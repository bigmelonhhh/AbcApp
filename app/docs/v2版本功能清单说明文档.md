# v2 版本功能清单说明文档

## 1. 范围与版本

- 项目：咕咕 ABC，面向 3 岁以上儿童的离线英语认知应用。
- 记录日期：2026-11-11；应用版本 `2.0`（versionCode 2），最低 Android 8 / API 26，目标 API 34。
- 本文依据当前工作区代码、词库及打包资源整理。历史实现见 v1 文档；本版替换旧首页与家长选课方式。

## 2. 首页与自主选课

- 首页以动物、水果、交通工具、生活用品四张大图片卡作为入口，展示中英文分类名。
- 点击分类后直接选图片小课，每张卡展示本课三个事物和中文标题；整张卡可点击。
- 动物 8 课分两页，每页 4 组；其他分类各 2 组，使用更高的双卡布局。翻页按钮和圆点提示当前位置。
- 从第一张单词卡返回时保留原分类和页码；选课页“首页”返回四分类。
- 首页可直接进入“我的贴纸”；点击“家长”即打开设置弹框，无需长按，不再显示长按提示或进度圈。

## 4. 学习与兴趣反馈

1. **认一认**：依次展示三张图卡、英文和中文名称，进页自动播报；点图片、喇叭或提示文案可重听。
2. **听一听**：三题二选一，选项只展示图片；目标左右交替。停留 10 秒会再播一次。
3. **答对啦**：保留小鸡、星星与鼓励音效；约 1.2 秒后可继续。选错只重播目标音频，不扣分。
4. **完成与复习**：完成本课三题后解锁三个贴纸；可再玩本课、换一组、看贴纸或休息退出。
5. **分类贴纸册**：切换四个分类；已解锁贴纸可点读，未解锁保持淡色且不可点读，不添加积分、排行榜或付费解锁。

干扰项取自同一分类的本课与已学词，排除同轮廓组与既有禁用组合；基准动物课保留原轮换规则。完成课的记录保存在本机，旧动物进度沿用。

## 5. 家长设置、每日额度与音频

- 家长面板包含固定 5 分钟上限说明、重置今日时长、声音开关、今日分钟数、合成语音告知和关闭按钮；20 秒自动关闭，不再放课程列表。
- 只在前台学习页面累计学习时长，分类浏览与贴纸册不累计；切换分类、换课、再玩和冷启动都不会重置同一天额度。
- 本地数据恢复完成前禁止进入学习；达到 300 秒后结束学习，新的学习入口也会检查额度。家长重置只清今日时长，不清贴纸与声音设置；跨日期清零。
- 音频为打包的美式英语电脑合成单词语音；应用内无 TTS 引擎、无联网播放、无录音。新增音频与原词库使用相同音色和慢速配置。
- 退后台立即停止并取消延迟重播；后台拒绝新的播放请求。返回前台后从当前学习页恢复播报，听音题重新计算提醒时间。

## 6. 技术维护入口

- `tools/word_packs.json`：分类、课包、词汇、图音文件名的唯一目录来源。
- `python tools/generate_catalog.py`：生成 `data/Words.kt`；`--check` 检查是否同步。新增分类由枚举驱动首页与贴纸筛选。
- `screens/HomeScreen.kt`：分类首页、图片选课与翻页；`state/GuguRoute.kt`、`SessionState.kt`、`GuguNavHost.kt`：路由、额度和音频生命周期。
- `state/QuizPicker.kt`：同类干扰项；`screens/StickerBookScreen.kt`：分类贴纸。
- `src/main/res/drawable-nodpi/img_*.png`、`res/raw/word_*.ogg`：实际离线媒体。
- `python tools/prepare_v2_assets.py audio --missing-only --commit`：仅生成缺少的语音；需要配置 Piper、模型和 libsndfile。
- 改中文文案后须重新生成字体子集；静态检查会验证新增字符覆盖。

## 7. 范围边界

- 没有语音识别、跟读评分、摄像头识物、账户、云同步、在线内容下载或自适应课程；主要交互为看图、听音与点选。
- 每次打开应用从首页开始，不恢复未完成的题目；累计时长、当前课程及已学贴纸会保存。
- 每日额度基于设备本地日期与本机存储，不是防改时钟或清应用数据的防作弊机制。
- 三岁以上是产品使用场景，应用未实现年龄测评或学习效果评估。
