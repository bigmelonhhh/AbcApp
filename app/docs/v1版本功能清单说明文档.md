## 1. 文档范围与核对依据

- 项目：咕咕 ABC（Gugu ABC），Android 离线英语启蒙应用。
- 整理及修订日期：2026-11-11；代码基线：`628b8d5` 加本轮每日额度与后台音频修复，以当前工作区代码为准。
- 应用配置：`versionName = "1.0"`、`versionCode = 1`，最低 Android API 26，目标 API 34。
- 本文的 **v1 是本次功能清单的版本**，记录当前已实现代码，包含源码注释中标为 V2 的课程扩展、贴纸册等功能，不仅限于历史首版。

代码路径均相对当前 `app/` 项目；下方源码链接相对本文所在的 `docs/` 目录。

## 2. 功能总览与学习流程

当前有 6 类页面：**首页、认一认、听一听、答对啦、今天真棒、贴纸册**，另有覆盖在页面上的家长设置面板。

正常完成一课的流程：

```text
首页「开始玩」
  → 认一认：按课程顺序浏览 3 张单词卡
  → 听一听：第 1 题 → 答对啦 → 第 2 题 → 答对啦 → 第 3 题 → 答对啦
  → 点击最后一次「再玩一个」：将本课 3 词记为已学
  → 今天真棒：再玩当前课 / 休息退出 / 查看贴纸册 / 家长设置
```

学习计时从不足 300 秒达到 300 秒时，也会进入“今天真棒”。额度已经用满后点击首页“开始玩”，同样进入该页并阻止进入单词卡。这两类跳转本身不会将本课标为已学。

依据：[GuguRoute.kt](../src/main/java/com/guguabc/kids/state/GuguRoute.kt)、[GuguNavHost.kt](../src/main/java/com/guguabc/kids/state/GuguNavHost.kt)、[SessionState.kt](../src/main/java/com/guguabc/kids/state/SessionState.kt)。

## 3. 已实现页面功能

| 页面 / 模块 | 当前功能与操作 |
| --- | --- |
| 首页 | 展示品牌、吉祥物、当前课程和 3 个单词插画；额度未用满时点击“开始玩”从本课第 1 张卡开始，已用满则转到完成页；本地设置尚未恢复时不进入学习；右上角提供家长入口。默认课程为第 1 课。 |

| 听一听 | 每课 3 题，按本课词序出题；显示目标英文提示和两个纯图片选项；进入题目自动播放目标词，提示条可点击重播；选错只重播目标词，保留题目；选对进入庆祝页；提供进度点、返回及音效开关。 |

| 今天真棒 | 展示当前课的 3 张词语贴纸、课程词汇和今日分钟数；额度未耗尽时“再玩一次”重开当前课；额度耗尽时点击该按钮，显示约 2 秒的家长重置提示；“休息啦”结束当前 Activity；提供贴纸册和家长入口。 |

## 4. 课程、出题与学习记录

### 4.1 内置课程

共 8 课、24 词，每课固定 3 词；每词已关联本地插画和单词音频。

| 课次 | 课程名称 | 标记 | 词汇（英文 / 中文） |
| --- | --- | --- | --- |
| 1 | 身边的小伙伴 | L1 | Cat / 小猫、Dog / 小狗、Bear / 小熊 |
| 2 | 农场里 | L1 | Pig / 小猪、Cow / 奶牛、Duck / 小鸭 |
| 3 | 草地上 | L1 | Rabbit / 兔子、Sheep / 绵羊、Horse / 马 |
| 4 | 池塘边 | L1 | Fish / 小鱼、Frog / 青蛙、Bird / 小鸟 |
| 5 | 树林里 | L1 | Fox / 狐狸、Monkey / 猴子、Deer / 鹿 |
| 6 | 动物园 | L1 | Lion / 狮子、Tiger / 老虎、Panda / 熊猫 |
| 7 | 大个子朋友 | L2 | Elephant / 大象、Giraffe / 长颈鹿、Zebra / 斑马 |
| 8 | 特别的朋友 | L2 | Owl / 猫头鹰、Turtle / 乌龟、Butterfly / 蝴蝶 |

L2 在家长课程列表中显示“大朋友”；当前没有等级解锁条件，8 课均可由家长直接选择。完成课程不会自动切换到下一课。

### 4.2 二选一出题规则

- 正确答案的位置按题目索引交替：第 1、3 题在左，第 2 题在右。
- 第 1 课使用固定课内干扰项：Cat 配 Dog、Dog 配 Bear、Bear 配 Cat。
- 第 2～8 课从“本课词 + 历史已学词”中去重选取干扰项，排除目标词、同分组词和禁用组合。
- 禁用组合为 Lion–Tiger、Cat–Lion、Dog–Fox、Duck–Bird、Horse–Zebra、Turtle–Frog。
- 候选按分组序号差的绝对值降序、词 ID 升序排列，再按题目索引、课号和会话种子确定性轮换；不是根据错误率自适应出题，也不是每次随机抽题。
- 候选为空时回退到本课下一个词。第 1 课不使用历史已学词作为干扰项。
- 不记录选错次数，不扣分，不产生错题本。

### 4.3 已学判定

只有在本课最后一题答对后的庆祝页点击“再玩一个”，才将整课 3 个词 ID 合并到已学集合，并保存到本地。单纯浏览单词卡、答对前两题、进入完成页或点击贴纸均不触发解锁。重复完成使用集合合并，不累计重复词数。

依据：[Words.kt](../src/main/java/com/guguabc/kids/data/Words.kt)、[word_packs.json](../tools/word_packs.json)、[QuizPicker.kt](../src/main/java/com/guguabc/kids/state/QuizPicker.kt)、[SessionState.kt](../src/main/java/com/guguabc/kids/state/SessionState.kt)。

## 5. 家长设置与每日时长

### 5.1 家长入口和设置项

- 入口位于首页、完成页右上角。实际长按阈值为 **1500 毫秒**，按住显示进度环，提前松手取消；短按只弹提示，不打开面板。
- 面板列出全部 8 课，显示当前选择、词语缩略图和 L2 标记，可滚动浏览。
- 点击课程后保存选择，关闭面板、停止音频、清空导航历史并回到首页；选择课程本身不会重置时长或清除已学词。
- “重置今日时长”将当前日期的计时清零，恢复重玩资格，显示约 2 秒“已重置”；不清已学词、课程选择和音效设置。
- 可切换全局音效，查看今日已玩分钟数及“单词发音由电脑合成”说明。
- 点击遮罩或“关闭”可收起面板；面板打开 **20 秒后自动关闭**，滚动或操作不会重启这个计时。

### 5.2 计时口径

| 项目 | 当前代码规则 |
| --- | --- |
| 上限 | 固定 `5 × 60 = 300` 秒，无自定义时长输入或档位。 |
| 学习入口 | “开始玩”与“再玩一次”在会话层统一校验本地数据已恢复、当前日期和剩余额度；重新启动或换课不会解除当日已用满的额度。 |
| 累计条件 | 应用处于前台生命周期状态，且路由为认一认、听一听或答对啦；循环每约 1 秒累计 1 秒。 |
| 不累计的正常页面 | 首页、完成页、贴纸册；家长面板目前从首页或完成页打开，底层路由也不计时。 |
| 达到上限 | 从不足 300 秒增长到 300 秒时，停止累计、清空导航历史、停止音频并进入完成页，只触发一次到点跳转；已用满时再尝试进入学习也会被拦截。首页和贴纸册单纯停留不会被计时器踢走。 |
| 分钟展示 | 秒数除以 60 后向上取整；例如 1 秒显示 1 分钟，61 秒显示 2 分钟。 |
| 跨天 | 按设备本地日期判断，在恢复数据或后续 tick 时清零时长；已学词保留。 |
| 保存频率 | 每累计 5 个学习秒请求保存；到点、跨天、重置和设置变化等路径也会请求保存。 |
| 旧值兼容 | 同日存储值超过 300 秒时，启动恢复会将其归零；负值按 0 处理。 |

依据：[ParentGateButton.kt](../src/main/java/com/guguabc/kids/design/components/ParentGateButton.kt)、[ParentPanel.kt](../src/main/java/com/guguabc/kids/state/ParentPanel.kt)、[TimeBudget.kt](../src/main/java/com/guguabc/kids/state/TimeBudget.kt)、[GuguNavHost.kt](../src/main/java/com/guguabc/kids/state/GuguNavHost.kt)。

## 6. 音频、交互与设备显示

- 运行时使用本地 `res/raw` 的 24 条单词 OGG、庆祝音和家长面板打开提示音，不依赖联网或实时 TTS；音频是否实际可闻仍受设备音量及播放状态影响。
- 本地设置恢复完成且应用处于前台时，单词卡、听力题进入时自动播放；听力题进入 10 秒后，如果仍在同一路由且仍在前台，再重播一次。手动重播或选错不会重置这 10 秒计时，不能描述为严格的“无操作 10 秒提醒”。
- 全局音效关闭时禁止新的播放请求，并停止当前音频；该开关覆盖单词发音和提示音。
- 播放器采用 `MediaPlayer` 异步准备并申请临时音频焦点；新播放先停止旧播放，使用代次标记隔离过期回调；错误记录到 `GuguAudio` 日志。
- 切换页面时停止旧音频；应用收到 `ON_STOP` 时立即停止当前播放并同步禁止新的会话播放请求，前台状态变化同时取消自动播报任务及尚未触发的 10 秒重播。界面销毁时释放资源。
- 收到 `ON_START` 回到前台后，若仍在单词卡、听力题或庆祝页，重新播放当前页音频；听力题从此重新等待 10 秒提醒一次，不补播后台期间到期的旧任务。音效关闭时仍保持静音。初次挂载界面时也读取实际生命周期状态，不默认视为前台。
- 使用 `guguClick` 的控件具有每个点击点 400 毫秒防连点、缩放到 0.97 后约 100 毫秒恢复的反馈；不是所有设置行都经过此封装。
- 路由切换采用 200 毫秒淡入淡出；学习翻页通过按钮完成。
- 应用锁定横屏，隐藏系统栏，关闭可调整窗口声明和 RTL 支持；以 1280 × 800 设计尺寸计算缩放，字体缩放固定为 1，不跟随系统字体大小。
- 使用自定义浅色主题及本地字体，没有深色模式或动态取色开关。最低 SDK 配置不代表所有设备已通过视觉验收。

依据：[AudioPlayer.kt](../src/main/java/com/guguabc/kids/audio/AudioPlayer.kt)、[GuguNavHost.kt](../src/main/java/com/guguabc/kids/state/GuguNavHost.kt)、[GuguShadow.kt](../src/main/java/com/guguabc/kids/design/GuguShadow.kt)、[GuguApp.kt](../src/main/java/com/guguabc/kids/GuguApp.kt)、[MainActivity.kt](../src/main/java/com/guguabc/kids/MainActivity.kt)、[AndroidManifest.xml](../src/main/AndroidManifest.xml)。

## 7. 本地数据与功能范围

应用通过 Preferences DataStore 的 `gugu_prefs` 保存以下数据：

| 存储键 | 含义 | 缺省值 |
| --- | --- | --- |
| `sound_enabled` | 全局音效开关 | 开启 |
| `today_date` | 计时所属日期 | 空字符串，启动时校正 |
| `used_seconds` | 当日累计学习秒数 | 0 |
| `current_pack_id` | 当前选择课程 | 第 1 课 |
| `learned_word_ids` | 已学单词 ID 集合 | 空集合 |

未知课程 ID 回退到第 1 课。当前路由、单词卡位置、题目位置、返回历史和会话种子仅保存在内存；重新创建会话从首页开始，不提供进程重启后的断点续学。

启动时异步恢复本地设置。在恢复完成前，学习入口、计时、选课、音效修改和时长重置均不执行，防止初始默认值绕过或覆盖已保存的额度。

当前实现未包含账号登录、多儿童档案、云同步、后台管理、在线课程下载、课程编辑、录音跟读、语音识别、发音评分、错题记录、历史每日学习报表或支付功能。Manifest 未声明权限，应用备份设置为 `allowBackup="false"`。界面没有清空全部已学记录的入口。

依据：[Prefs.kt](../src/main/java/com/guguabc/kids/state/Prefs.kt)、[SessionState.kt](../src/main/java/com/guguabc/kids/state/SessionState.kt)、[GuguRoute.kt](../src/main/java/com/guguabc/kids/state/GuguRoute.kt)、[AndroidManifest.xml](../src/main/AndroidManifest.xml)。

## 8. 修复记录、当前边界与文案差异

### 8.1 本轮已修复问题

| 问题 | 修复后的行为与验证 |
| --- | --- |
| 每日 5 分钟限制可从首页绕过 | `start()` 与 `replay()` 共用入口校验；恢复完成前不放行，进入前先校正日期，再检查额度。已用满后启动、换课均不能进入学习；家长主动重置或次日恢复后可以开始。冷启动用满后的回归测试曾在旧代码上失败，修复后通过。 |

### 8.2 仍存在的边界

以下为当前源码行为；本轮仅修复上述两项，未调整下表中的文案与业务口径。

| 边界 | 代码中的实际情况 |
| --- | --- |
| 完成页不等于已学记录 | 到点跳转或额度耗尽后的入口拦截也使用同一个完成页。该页收到的是 `currentPack.words`，仍展示 3 词及“认识了 3 个新朋友”；并未据实际完成状态过滤，不能据此认定已解锁贴纸。 |
| 最后一题答对不立即解锁 | 必须再点击最后庆祝页的继续按钮；此前退出、返回首页或到点，不会执行整课标记。 |
| 家长长按提示与阈值不同 | 短按提示写“长按……2 秒”，实现阈值为 1.5 秒。 |
| 每日上限不可编辑 | 完成页提示含“可设置每日时长”，实际面板只显示固定 5 分钟并支持重置，没有修改上限的控件。 |
| 本地时长不是逐秒持久化 | 常规计时每 5 秒请求保存，写入也是异步的；进程突然结束时不能承诺最后几秒完全保留。`ON_STOP` 路径没有额外刷新计时存储。 |

依据：[SessionState.kt](../src/main/java/com/guguabc/kids/state/SessionState.kt) 的 `start` / `replay` / `continueFromCheer` / `persist`，[TimeBudget.kt](../src/main/java/com/guguabc/kids/state/TimeBudget.kt) 的 `tick`，[GuguNavHost.kt](../src/main/java/com/guguabc/kids/state/GuguNavHost.kt) 的完成页传参与音频副作用，以及 [Strings.kt](../src/main/java/com/guguabc/kids/data/Strings.kt)。
